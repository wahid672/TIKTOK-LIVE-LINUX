Cara Kerja Live Stream Standalone

Aplikasi ini mengalirkan konten web langsung ke server RTMP TikTok tanpa membebani komputer dengan OBS Studio:

Simpan Setingan & Cache Buster
Judul siaran dan URL overlay dapat disimpan permanen. Fitur Hapus Cache memastikan file CSS/JS overlay yang baru Anda edit langsung aktif tanpa tertahan cache.
Suara Desktop & Musik Lengkap
Sistem menangkap output audio desktop secara otomatis. Musik dari Spotify, YouTube, tab browser lain, atau pemutar musik langsung masuk ke live.

Langkah Penggunaan:

  1. Buka browser di Linux (Google Chrome atau Chromium) dan pastikan akun Anda sudah login di tiktok.com.
  2. Tuliskan Judul Siaran dan tentukan URL Web Overlay yang ingin ditampilkan (atau gunakan bawaan).
  3. Klik tombol Simpan Setingan agar pengaturan Anda tersimpan secara otomatis setiap kali membuka dashboard.
  4. Jika Anda mengubah styling CSS pada overlay Anda, klik tombol Hapus Cache Overlay untuk memuat perubahan visual secara instan.
  5. Klik tombol hijau Mulai Live Sekarang. GStreamer akan memulai siaran langsung ke TikTok.
  6. Setelah selesai siaran, klik Akhiri Siaran Live agar room ditutup resmi di TikTok.
